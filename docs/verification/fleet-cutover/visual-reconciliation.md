## Preserved task differences and remaining gates

Long private evidence/response readers intentionally use more vertical space than
collections; mobile tables can become aligned factual records. Projector content,
media galleries and printable/offline exports use their own supported reading
composition. Offline run-sheet HTML owns inline styles and does not import the
removed frontend selectors. Current privacy/print guards remain authoritative.
The independent guide uses production tokens/controls with synthetic local state.

The visual findings changed four production owners using only existing button
variants and one existing-state-derived presentation predicate. Handlers, current
capabilities, disabled conditions, command identity, payload, confirmation, focus
and receipt rules are unchanged. The guide documents that rule for future changes.

Still required for full245: the current native-contract/nested-owner reconciliation,
its explicit positive-path gaps, integrated mentor advisory routes/source,
current-schema normal runtime/guide isolation and final native qualification
captures, full independent reviews and all current-head CI. A historical domain
image, source-path map, green component suite or this document cannot clear those
remaining gates by itself.
